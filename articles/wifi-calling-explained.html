WiFi Calling คืออะไร? ทางรอดของคนอยู่จุดอับสัญญาณ

คอนโดชั้นใน ห้องหลังตึก ชั้นใต้ดินห้าง — จุดที่คลื่นมือถือเข้าไม่ถึง แต่ WiFi ยังแรง WiFi Calling ให้เบอร์ของเราโทรออก-รับสายผ่านเน็ตบ้านได้เหมือนมีเสาสัญญาณอยู่ในห้อง

WiFi Calling (บางค่ายเรียก VoWiFi) คือการยกช่องทางเสียงโทรศัพท์ของเบอร์เราไปวิ่งผ่านเครือข่าย WiFi แทนคลื่นมือถือ โดยที่ปลายทางไม่รู้ความแตกต่างเลย — เบอร์เดิม โทรเข้า-ออกปกติ SMS มาตามปกติ

ต่างจากโทรผ่านแอป (LINE, Messenger) ยังไง

ประเด็นWiFi Callingโทรผ่านแอปแชต
เบอร์ที่ใช้เบอร์มือถือจริงของเราบัญชีแอป — อีกฝ่ายต้องมีแอปเดียวกัน
รับสายจากใครก็ได้ได้ รวมถึงเบอร์บ้าน เบอร์ call centerเฉพาะคนในแอป
ค่าบริการคิดเหมือนโทรปกติตามโปรเสียงใช้ปริมาณเน็ต
คุณภาพเสียงระดับ HD Voice เมื่อเน็ตนิ่งแกว่งตามแอปและเน็ต

หลักการทำงาน

เมื่อเปิดใช้งาน เครื่องจะสร้างอุโมงค์เข้ารหัสจากมือถือ ผ่านเราเตอร์และอินเทอร์เน็ต ตรงเข้าระบบของค่ายมือถือ เสียงโทรจึงปลอดภัยระดับเดียวกับการโทรผ่านเสา และเมื่อเดินออกนอกรัศมี WiFi เครื่องรุ่นใหม่ส่วนใหญ่จะสลับสายกลับไปที่เครือข่ายมือถือให้อัตโนมัติ (ทำงานร่วมกับ VoLTE ซึ่งควรเปิดคู่กันเสมอ)

วิธีเปิดใช้

เงื่อนไขแรก: ทั้งเครื่องและค่ายต้องรองรับ — เช็คได้ในเมนูตั้งค่าเครือข่ายว่ามีสวิตช์ "WiFi Calling" หรือไม่ และซิมของเราต้องเปิดบริการนี้กับเครือข่าย (บางค่ายเปิดให้อัตโนมัติ บางกรณีต้องติดต่อ call center ก่อน)
Android: ตั้งค่า → เครือข่ายมือถือ → WiFi Calling → เปิด
iPhone: ตั้งค่า → เซลลูลาร์ → การโทรผ่าน Wi-Fi → เปิด

ใช้คู่กับโปรเน็ตยังไงให้ครบวงจร

WiFi Calling แก้ปัญหา "เสียง" ในจุดอับ แต่พอออกนอกบ้านก็ยังต้องมีเน็ตมือถือที่นิ่งพอ — เลือกโปรตามพฤติกรรมได้จาก วิธีเลือกโปรตามการใช้งานจริง หรือเข้าดูโปรทั้งหมดที่หน้า โปรเน็ต AIS และ โปรทรู-ดีแทค ส่วนใครที่สัญญาณในบ้านอ่อนทั้งเสียงทั้งเน็ต อ่านเพิ่มที่ ทำไมบางจุดถึงไม่มีสัญญาณ
