จัดทำ: 01.08.2026 · สถานะ: **แผนอนาคต — ยังไม่ลงมือทำ** (รอ owner เลือก batch)
เก็บไว้บน branch หลักในโฟลเดอร์ `docs/` โดยเจตนา — ไฟล์บน branch `pronetserm` ทุกไฟล์ถูก deploy เป็นไฟล์สาธารณะบนเว็บ ไม่ควรให้แผนคีย์เวิร์ดเปิดดูได้

## ที่มาของตัวเลข (อ่านก่อนใช้)

ตัวเลข search volume ในเอกสารนี้เป็น **ประมาณการเป็นช่วง (Tier)** จากข้อมูลพฤติกรรมการค้นหาไทยถึงต้นปี 2026 — ไม่ใช่ตัวเลขที่ดึงสดจากเครื่องมือ (sandbox เข้าถึง Keyword Planner/Ahrefs ไม่ได้) **ก่อนลงมือเขียนแต่ละ batch ให้ยืนยันด้วยเครื่องมือจริงก่อนเสมอ:**

1. **Google Keyword Planner** (ฟรี ต้องมีบัญชี Google Ads) — Tools → Keyword Planner → Discover new keywords → ตั้ง Location = Thailand, Language = Thai แล้ววางคีย์เวิร์ดจากตารางนี้ทีละกลุ่ม ได้ช่วง volume จริงต่อเดือน
2. **Ubersuggest** — ฟรี 3 ครั้ง/วัน เช็คคำหัวของแต่ละ cluster
3. **Google Trends ไทย** (`trends.google.co.th` เลือกประเทศไทย) — ใช้เทียบ *ลำดับ* ระหว่างคำ (คำไหนใหญ่กว่ากัน) และดูฤดูกาล เช่น เทียบ `eSIM` กับ `ย้ายค่ายเบอร์เดิม`

| Tier | ช่วงประมาณ (ครั้ง/เดือน, ไทย) | ความหมายเชิงกลยุทธ์ |
|---|---|---|
| **S** | 50,000+ | คำหัวใหญ่ — หน้าแรกมักเป็นเว็บค่าย/เว็บใหญ่ ชิงยากตรงๆ ให้ทำ long-tail ที่ห้อยจากคำนี้ |
| **A** | 10,000–50,000 | สูง — ชิงได้ถ้า intent ตรงและหน้าเราลึกกว่า |
| **B** | 1,000–10,000 | เป้าหลักของเว็บเรา — เว็บเล็ก authority พอสู้ได้ |
| **C** | 100–1,000 | long-tail แท้ — แข่งต่ำ ทำสะสมเป็นกลุ่มแล้วคุ้ม |
| **D** | <100 | ทำเฉพาะเมื่อเป็นส่วนหนึ่งของ hub ไม่ทำเดี่ยว |

หลักการเดียวกับ 65 หน้าที่ผ่านมา: **ห้าม URL/เนื้อหาซ้ำ, ราคา/รหัส USSD ต้องมาจาก `data/packages.json` เท่านั้น (ห้าม invent), บล็อกข้อความ generic ห้ามซ้ำข้ามหน้า** — เนื้อหาเทคโนโลยี/ความรู้ทั่วไปเขียนได้อิสระเพราะไม่ใช่ข้อมูลราคา
