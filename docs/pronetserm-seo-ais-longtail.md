## 4. สิ่งที่ทำแล้ววันนี้ (commit `7fcd52e` บน `pronetserm`)

1. **หน้า AIS×ความเร็ว 5 หน้า**: `/ais/1mbps` (รวม 512Kbps กันหน้าบาง), `/ais/2mbps`, `/ais/4mbps`, `/ais/6mbps`, `/ais/10mbps` — แต่ละหน้า: ตารางโปร AIS เรียงราคาเฉลี่ยต่อวัน + ตาราง "รอบเวลาไหนถูกสุด" + intro/FAQ เขียนเฉพาะหน้า (มีคำว่า "X เมก" แบบภาษาพูดที่คนใช้ค้นจริง) + Product/FAQ JSON-LD
2. **Internal links**: เมนู dropdown AIS เพิ่ม 5 รายการ (ทุกหน้าทั้งเว็บ), หน้า `/ais.html` เพิ่มบล็อกปุ่ม "เลือกตามความเร็ว", related links ไขว้ สปีดข้างเคียง ↔ hub ↔ หน้า cross-carrier `/speed/*`
3. Audit ผ่าน: ราคา/รหัส USSD ตรง `packages.json` ทุกตัว (ห้าม invent — ตรวจอัตโนมัติ), JSON-LD parse, ลิงก์ไม่เสีย, AdSense 1×/หน้า, Chromium ไม่มี error, sitemap → 104 URLs

## 5. งานต่อ (เรียงตามผลตอบแทน — รอเคาะ)

1. **ยืนยัน volume จริง** ใน Keyword Planner (คอลัมน์ Tier ข้างบน) — 15 นาที ฝั่ง owner
2. **Submit sitemap ใหม่ใน GSC** + ขอ index 5 URL ใหม่ (URL Inspection → Request Indexing)
3. หลัง 2–3 สัปดาห์: อ่าน GSC ว่า 5 หน้าใหม่เริ่มมี impressions ที่คำไหน → เสริมหน้าที่ขยับก่อน
4. Batch ถัดไป (ยังไม่ทำ): หน้า True/dtac ×สปีด แบบเดียวกัน (dtac มี 512kbps/1/2/4/10 · true มี 1 Mbps — บาง ต้องจัดกลุ่ม), หน้า "โปรเน็ต ais ราคา X บาท" ตามงบ (คู่แข่ง one2callonline ใช้สูตรนี้ติด)
5. Backlink ช่วยเร่ง: ทำตาม `backlink-execution-kit.md` ฝั่ง SwissCalc ก่อน — pronetserm ยังไม่จำเป็นเร่งลิงก์ (long-tail กลุ่มนี้คู่แข่ง DA ต่ำพอกัน ชนะกันที่หน้า+เนื้อหา)

**คำตอบคำถาม "เราพอมีทางทำอันดับได้ไหม": ได้** — หลักฐานคือเว็บ affiliate ระดับเดียวกับเราติดหน้าแรกให้เห็นเป็นแถวในทุกคำ long-tail ที่เช็ค และเราเพิ่งอุดช่องว่างเชิงโครงสร้าง (แกนความเร็ว) ที่เราแพ้เขาอยู่จุดเดียว
