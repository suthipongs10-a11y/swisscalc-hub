# แผน SEO โปรเน็ตเสริม.com — วิเคราะห์ความเป็นไปได้ + แผน 90 วัน

จัดทำ 02.09.2026 · สถานะเว็บ: 115 หน้า ออนไลน์ครบ (deploy ผ่าน Wrangler) · เอกสารพี่น้อง: `pronetserm-seo-ais-longtail.md` (matrix สปีด×วัน), `pronetserm-keyword-research.md` (คลัง keyword)

## 0. ข้อสรุปสั้น (อ่านข้อนี้ข้อเดียวก็พอ)

1. **"เจาะเฉพาะโปร 1 หน้า" = ถูกทาง และ SERP พิสูจน์แล้ว** — คำค้นแบบ "โปรเน็ต ais 40 บาท รายวัน 4mbps" ติดหน้าแรกด้วยเว็บเล็กที่มี*หน้าโปรเดียว*ทั้งนั้น (samuknet.com/ais-4mbps-40…, pronetja.com/ais-4mbps-40, package12call.com/internet-daily-40-baht) — **เว็บเรามีหน้าแบบนี้อยู่แล้ว 38 หน้า** (`/pro/*.html`) แต่ยังบาง (300–366 คำ) ต้องอัปเกรด ไม่ต้องสร้างใหม่
2. **คอขวดอันดับหนึ่งไม่ใช่ SEO แต่คือความสดของราคา** — SERP แสดงคู่แข่งขาย AIS 10 Mbps/30 วัน 200 บาท และ 4 Mbps/30 วัน 200 บาท (one2callonline, aissupernet, aisnet5g, Pantip) ส่วน data เรา: 10 Mbps/30 วัน 1,177 บาท · 4 Mbps/30 วัน 470–696 บาท → ต้องให้ owner ตรวจกับระบบตัวแทน AIS แล้วอัปเดต `data/packages.json` (ผมแก้ราคา/รหัสเองไม่ได้ตามกติกา) — **ถ้าไม่ทำข้อนี้ ทุกอย่างที่เหลือไร้ผล**
3. ความเป็นไปได้: หัวคำใหญ่ (โปรเน็ต ais) = AIS ครองเอง ไม่แตะ · กลุ่มกลาง (ตามวัน/สปีด) = ติดหน้าแรกได้ใน 2–4 เดือน · long-tail ต่อโปร/ต่อราคา = 1–3 เดือน — **มีเงื่อนไขว่าราคาตรงตลาด + หน้าโปรถูกอัปเกรด + มี GSC คอยวัด**

## 3. คำถาม "เจาะเฉพาะโปร 1 หน้า" — ทำยังไงให้ชนะ (สเปกอัปเกรดหน้า `/pro/`)

ไม่เปลี่ยน URL (กัน index หาย) แต่ทำแต่ละหน้าให้เป็น "หน้าเดียวจบ" ของโปรนั้น:
1. **ความยาว 300 → 600–800 คำ** ด้วยบล็อกที่ต่างกันจริงต่อโปร: "โปรนี้เหมาะกับใคร" (มี) + "โปรนี้ทำอะไรได้ในหนึ่งวัน/เดือน" (คำนวณจากสปีดจริง เช่น ดูวิดีโอ HD ได้กี่ชั่วโมงต่อวัน — เป็นความรู้เทคนิค ไม่ใช่ราคา) + "เทียบเฉลี่ยต่อวันกับรอบสั้น/ยาวของสปีดเดียวกัน" (มีตารางแล้ว ขยายเป็นข้อความ) + "ก่อนกด: เช็คยอด/วันใช้งาน" + "หมดแล้วทำไง: สมัครซ้ำ/ยกเลิก" (ลิงก์บทความ)
2. **FAQ 3 → 5 ข้อ** ตอบคำถามที่คนถามจริงต่อโปร: ต่ออายุอัตโนมัติไหม · ใช้กับซิมรายเดือนได้ไหม · ระบบเติมเงินต้องมียอดเท่าไหร่ · แชร์ฮอตสปอตได้ไหม · ต่างจากรุ่น 4G/5G ยังไง
3. **กราฟิกต่อโปร** (SVG generate): แถบ "ราคาเฉลี่ยต่อวัน" เทียบพี่น้องในสปีดเดียวกัน + ป้าย "ทำอะไรได้" ระดับสปีด (นำ infographic ของหน้า AIS×สปีดมาย่อ)
4. **Title/H1 ใส่คำที่คนพิมพ์**: เพิ่ม variant "X เมก" ในเนื้อหา, คำว่า "รหัสสมัคร *777…" อยู่ใน description แล้ว — ดี
5. **ลิงก์ไขว้ 3 ทิศ**: hub วัน + hub สปีด (AIS×สปีด) + หน้า "ตามราคา" (ใหม่) — ตอนนี้ลิงก์ในหน้า pro ไปแค่ hub ค่าย/สปีดทุกค่าย

## 4. หน้าใหม่ที่ควรมี (เฉพาะที่ data รองรับ)

| หน้า | ทำไม | เงื่อนไข |
|---|---|---|
| **"ตามราคา" AIS**: `/ais/price-40.html` (โปรเน็ต ais 40 บาท), 59, 105, 130, 236, 470… | คำค้นแบบ "โปรเน็ต ais 40 บาท" ติดด้วยหน้าราคาเดียว (package12call) — เราไม่มีเลย | สร้างจาก packages.json อัตโนมัติ เฉพาะราคาที่มี ≥1 โปร (ราคาเดียวมีหลายโปรก็ยิ่งดี เช่น 59 บาท มี 4Mbps 2วัน + 10Mbps 1วัน) |
| True/dtac × สปีด | เติมแกนสปีดให้ครบทุกค่าย | dtac มี 5 สปีด · True มี 1 (บาง — รวมเป็นหน้าเดียว "True ทุกสปีด") |

| หน้าโปรใหม่ตามตลาด (10 Mbps 200 บาท ฯลฯ) | ตามข้อ 0.2 | รอ data จาก owner |

## 5. แผนงาน 90 วัน

**สัปดาห์นี้ (owner):**
- [ ] ตรวจ package list ปัจจุบันจากระบบตัวแทน AIS/True/dtac → ส่งรายการ (ชื่อ สปีด วัน ราคา รหัส) ให้ผมใส่ `packages.json` แบบ verbatim — โดยเฉพาะโปร 30 วัน ที่ตลาดอยู่ที่ 200 บาท
- [ ] เพิ่ม property `โปรเน็ตเสริม.com` ใน Google Search Console (ยืนยันผ่าน DNS ใน Cloudflare) → submit `sitemap.xml` → Request Indexing หน้า hub หลัก 10 หน้า
- [ ] Cloudflare: Preview deployments = None (เมื่อ GitHub กลับมา)

**เดือน 1 (ผมทำ เมื่อเคาะ):** อัปเกรด 38 หน้า `/pro/` ตามสเปกข้อ 3 + สร้างหน้า "ตามราคา" AIS + True/dtac×สปีด + ตรวจ internal link mesh ทั้งเว็บ (ทุกหน้าต้องมีทางเข้า ≥3 ทาง)
**เดือน 2:** อ่าน GSC รอบแรก → แก้ title/description หน้าที่มี impressions แต่ CTR ต่ำ · batch บทความที่เหลือ (minimum-topup, dual-sim, kids-smartwatch, sim-cctv, apn-settings) · เพิ่ม "อัปเดตล่าสุด" จริงเมื่อราคาเปลี่ยน (สัญญาณความสด)
**เดือน 3:** สร้างสัญญาณภายนอกเบาๆ — ตอบกระทู้ Pantip ที่ถามเรื่องซิม/โปรพร้อมเปิดเผยตัว, โปรไฟล์ธุรกิจ TKShop (Facebook/LINE OA/Google Business ถ้ามีหน้าร้าน), คลิปสั้น "กดรหัสยังไง" ลิงก์กลับ · วัดผล: ≥30 หน้ามี impressions, ≥5 คำติด top-10, คลิกแรกจากหน้าโปร

**KPI 90 วัน:** index ≥100/115 หน้า · impressions/สัปดาห์โตต่อเนื่อง · หน้า `/pro/` อย่างน้อย 5 หน้าติด top-10 ในคำ "โปรเน็ต ais <สปีด> <วัน>" · AdSense RPM เริ่มนับได้
