## 0. หลักการ (อ่านก่อนลงมือ)

1. **White-hat เท่านั้น** — ห้ามซื้อลิงก์, ห้าม PBN, ห้ามแพ็กเกจ Fiverr, ห้าม comment spam
   เว็บอายุไม่ถึงปี ถ้าโดน manual action ตอนนี้คือจบ
2. **ลิงก์คุณภาพ 3–5 ลิงก์/เดือนพอ** สำหรับเว็บใหม่ ความสม่ำเสมอสำคัญกว่าจำนวน
3. **Anchor ธรรมชาติ** — ส่วนใหญ่ควรเป็น brand/URL ("CalcSwiss", "calcswiss.ch") หรือประโยคบรรยาย
   ("free Swiss withholding tax calculator") ห้ามยิง exact-match keyword ("quellensteuer rechner") ซ้ำ ๆ
4. **ให้ค่าก่อนขอลิงก์** — ทุกโพสต์ในฟอรัม/Reddit ต้องตอบคำถามคนได้จริงแม้ตัดลิงก์ออก
5. **เปิดเผยตัวเสมอ** ("I built this") — ชุมชนสวิส/expat จับโฆษณาแฝงไวมาก โดนแบนแล้วกู่ไม่กลับ
6. **ติดตามผล**: GSC → Links report + สมัคร [Ahrefs Webmaster Tools](https://ahrefs.com/webmaster-tools) (ฟรี
   สำหรับเว็บตัวเอง — เห็น referring domains/anchors) + สเปรดชีตบันทึก: วันที่ / แหล่ง / URL โพสต์ /
   หน้าเป้าหมาย / สถานะ (live, removed, nofollow)

## Tier B — ชุมชน: ตอบคำถามจริง แล้วลิงก์ตามบริบท (เริ่มสัปดาห์ 2, ทำต่อเนื่อง)

## Tier D — Data-PR: แรงสุด ใช้ของที่มีอยู่แล้ว (เดือน 2–3)

เรามีสิ่งที่เว็บคู่แข่งส่วนใหญ่ไม่มี: **ชุดข้อมูลเปรียบเทียบครบทุกกันตันพร้อมแหล่งอ้างอิง** — นักข่าวชอบตัวเลขสำเร็จรูป

### D1. story ที่ผลิตได้จากข้อมูลปัจจุบัน (ไม่ต้องสร้างอะไรใหม่)
1. "ย้ายกันตันประหยัดภาษีสูงสุดกี่ CHF ที่เงินเดือน 80k/100k/150k" — จาก `/steuervergleich/`
2. "Quellensteuer เงินเดือนเท่ากัน ต่างกันตันต่างกันเท่าไร" — จากข้อมูล QST 26 กันตัน
3. seasonal hook: ช่วงปลายปี = ฤดู Säule 3a (deadline ธ.ค.) + ฤดูประกาศ premium Krankenkasse (ก.ย.–ต.ค.)
   เตรียม pitch ล่วงหน้า 1 เดือน

### D2. แพลตฟอร์มรับคำถามนักข่าว (แทน HARO ที่ปิดไปแล้ว)
